# The Eorzean Bestiary Compendium for FoundryVTT

The Eorzean Bestiary serves as a massive repository for all the types of beasties, foes and other neer-do-wells you might want to populate your adventures.

This bestiary will include not just every enemy included in the Enemy Data list in the GM book, but also all enemies included in the scenarios (such as the starter kit, player's book and GM book) 
as well as those included in the DLC scenarios that have been released online.

**!! This module is currently in dev/beta at the moment and only includes a few monsters!! You can follow development and suggest features on the TTRPG Discord !!**

## Requirements
- FFXIV TTRPG System for Foundry
- AxeBane's FFXIV Compendia module

## Currently Included
- All Beastkins
- Scenario 4 enemies (The Beast Tamer's Flute)
- A handful of other enemies for testing purposes
